PATCH KITLAB6 PUBLIC BETA PREP v0.2

Base:
- Preparacion publica con configuraciones estaticas desde kitlab-data/templates.

Reglas publicas exactas aplicadas:
1) Settings > Texture Wrinkles queda oculto en la web publica.
   - La textura VillaPilla se mantiene activa internamente.
   - Se fuerza el stack por defecto:
     VillaPilla texture = overlay 50%
     VillaPilla texture copy = multiply 100%
   - El usuario publico no puede cargar, duplicar ni modificar estas texturas desde la UI.

2) Save Template Settings queda oculto y bloqueado.
   - Nadie puede guardar configuraciones maestras de template en la web publica.

3) Export Template Settings queda oculto y bloqueado.
   - Nadie puede exportar configuraciones maestras de template en la web publica.

4) Todas las carpetas SEAMS quedan ocultas en la UI publica.
   - Seams de template y seams de collar no se renderizan como controles editables.
   - Las seams siguen cargando y renderizando internamente para que el template luzca correcto.
   - El usuario no puede tocar opacidad, inversion, visibilidad ni controles de esas seams desde la web.

5) El resto de KitLab queda visible segun estaba en la base.
   - No se oculta Export Brand state.
   - No se oculta Reset Brand.
   - No se oculta Base Design desde este parche.
   - No se ocultan galerias, collars, patterns, details, sponsors, team, brand ni export PNG.

Archivos:
- app.js
- kitlab-data/templates/...
- tools/kitlab6_public_collar_shield.py

Instalacion:
1) Copiar app.js, kitlab-data y tools dentro de la carpeta publica del repo:
   F:\KitLab6\GitHub-kitlab6-public-beta\kitlab6-public-beta
2) Reemplazar app.js.
3) Probar con:
   python -m http.server 8000
   http://localhost:8000
4) No hacer Commit/Push hasta confirmar que:
   - cargan configuraciones de templates,
   - Texture Wrinkles no se ve,
   - Save/Export Template Settings no se ven,
   - SEAMS no aparece en template ni collar,
   - las seams siguen renderizando en el kit,
   - el resto funciona.

Collar Shield:
- La herramienta se incluye, pero NO se ejecuta automaticamente.
- Ejecutarla solo despues de validar que la version publica funciona bien:
  python tools\kitlab6_public_collar_shield.py
